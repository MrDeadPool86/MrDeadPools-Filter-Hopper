## [ENG]

A simple hopper with a configurable item filter for NeoForge 1.21.1.

### Features

- **5 Ghost Slots** — configure up to 5 different item templates simultaneously
- **Filtered transfer** — only items matching a template are transferred
- **No filter = everything blocked** — if no template is set, no items are transferred
- **Directional** — faces all directions like a vanilla hopper
- **Multiplayer compatible** — all players see the same filter templates in real time
- **No dependencies** — works without any additional mods

### Usage

1. Place the Filter Hopper and orient it towards the target inventory
2. Right-click → fill the ghost slots with your desired item templates
3. Place an inventory above the hopper
4. Done — the hopper will only transfer the filtered items

### Compatibility

- **Minecraft:** 1.21.1
- **ModLoader:** NeoForge
- **Dependencies:** none
- **Side:** both (Client + Server)

Ein Hopper mit konfigurierbarem Itemfilter für NeoForge 1.21.1.

- **5 Ghost-Slots** — bis zu 5 verschiedene Item-Templates gleichzeitig konfigurierbar

- **Multiplayer-kompatibel** — alle Spieler sehen die gleichen Filter-Templates in Echtzeit
- **Keine Abhängigkeiten** — funktioniert ohne weitere Mods

### Verwendung

1. Filter Hopper platzieren und in Richtung des Ziel-Inventars ausrichten
2. Rechtsklick → Ghost-Slots mit gewünschten Item-Templates befüllen
3. Inventar über dem Hopper platzieren
4. Fertig — der Hopper transportiert nur die gefilterten Items
